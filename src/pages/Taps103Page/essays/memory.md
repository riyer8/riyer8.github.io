## The Path is Already Made

The narratives that we create through improv evolve through collaboration. Through shared memory exercises, we come together to build a story with collective meaning, especially through word-at-a-time exercises. Our collaborative storytelling evolves the narratives we show, requiring attentiveness and encouraging active listening.

In fact, with improv stories, all the offers and pieces were provided back. To build the story, we can continuiously connect it to past experiences and references, tying the story long the path we've already taken.

### Activities

- Word-at-a-time proverb
- Shared Memory
- Name Ball (sequence-based)
- Story Threads
