## The Path is Already Made Created 🧩

The narratives that we create through improv evolve through collaboration. Through shared memory exercises, we come together to build a story with collective meaning, especially through word-at-a-time exercises. Our collaborative storytelling evolves the narratives we show, requiring attentiveness and encouraging active listening.

**In fact, with improv stories, all the offers and pieces were already provided to us.** To build the story, we can continuously connect it to past experiences and references, tying the story along the path we've already taken.

In order to create the story, we must remember what we've done before. It's important to remember the names of our fellow actors, providing an insight of realism (especially if the act establishes that they've known each other for a while). Additionally, in improv, fellow actors will endow you with characteristics, quirks, ideas about you. Having an accurate sense of memory and listening ensures you stay true to the story already provided for you.

### Activities

- 🗣️ Word-at-a-time Proverb
- 🧠 Shared Memory
- 🏀 Name Ball (sequence-based)
- 📜 Story Threads
